NORTHSTAR is a finance workspace that brings sales, production, stock, supply and finance data into one place.

## What you can do

- Review each department on its own page
- Import the files a department needs
- Generate a report for any date range

## Workspace layout

The workspace has three columns:

| Column | Purpose |
| --- | --- |
| Left sidebar | Department navigation, help and settings |
| Main column | Department dashboard and actions |
| Account sidebar | Workspace context and data readiness |
